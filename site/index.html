What it does

One place for everything you download.

Garia runs the battle-tested aria2 engine for you — no Terminal, no config files — and wraps it in an app that feels like it shipped with your Mac.

Video pages

Paste a video link. Pick a quality.

Drop in a page from YouTube or a thousand other sites and Garia shows every quality it can get — up to 4K60, or just the audio. Video and sound download in parallel and are merged for you, without re-encoding.

  • Whole playlists and channels, with a rule for which quality to take
  • Streams go through the same fast engine as every other file
  • yt-dlp and ffmpeg are bundled — nothing extra to install

Batches

Paste twenty links. Keep the ones you want.

Paste a list, drop links on the window, or send every link on a web page from the browser extension. Garia names each file, lets you untick the extras, and starts them now, queues them, or holds them for a time you choose.

  • HTTP, HTTPS, FTP folders, magnet links and .torrent files
  • Optional checksum — paste a hash and aria2 verifies as it downloads
  • Categories sort new files into folders by type or by site

Torrents

Torrents, without a second app.

Open a magnet or a .torrent and it sits in the same list as everything else. Pick just the files inside you need, watch peers and ratio in the detail panel, and tell Garia when to stop seeding.

  • Per-download speed limits: Full, Medium or Light
  • Give any single download its own start time
  • Play a video before it finishes, when the front is on disk

And the rest

The small things that make it yours.

  • Browser capture

    An extension for Chrome, Firefox, Edge, Brave, Arc and Safari. Click a file and Garia takes it — hold ⌥ to leave it with the browser.

  • Scheduler

    A daily download window, a start time on any file, and Stop Queue / Start Queue from the menu, the Dock or the header.

  • Traffic modes

    Full, Medium or Light — for everything at once, or just the one download that's hogging the line during your video call.

  • Closes, keeps going

    Close the window and downloads keep running from the menu bar. Only ⌘Q stops them. Queues survive restarts.

  • Sleep when done

    When the last download finishes, do nothing, put the Mac to sleep, or shut it down — after a 30-second warning.

  • Downloads behind a login

    Saved user name and password per site, custom headers, browser cookies, and an HTTP proxy with its own login.

  • Checksum verification

    Paste an MD5 or SHA hash next to the URL. Garia names the algorithm itself and marks the file Verified.

  • Remote control

    Open the engine to your local network and pair a phone by scanning a QR code. Off by default.

  • Mac through and through

    Real menus, keyboard shortcuts, drag a file out to Finder, notifications, a Dock badge, and light and dark mode.

Get started

Install Garia in a minute.

Garia is an alpha — it's already a daily driver, but expect rough edges. Reports are very welcome.

1 Download the app

Get the universal .dmg — one app for Apple Silicon and Intel — then drag Garia to Applications.

Download for Mac
macOS says Garia can't be opened?

Early builds may not be notarized by Apple yet. Open System Settings → Privacy & Security, scroll down, and click Open Anyway next to Garia. Or, in Terminal:

xattr -dr com.apple.quarantine /Applications/Garia.app

2 Or use Homebrew

Install from the Garia tap. After that, Garia updates itself from the Garia menu.

brew tap fabimc/garia
brew trust fabimc/garia
brew install --cask garia

3 Add the browser extension

In Garia, open Settings → Browser → Show extension folder, then load it in your browser. Store listings are on the way.

FAQ

Questions, answered.

Is Garia really free?

Yes. Garia is open source under the MIT license — no trial, no pro tier, no ads. The bundled aria2 is GPL-2.0-or-later, ffmpeg is LGPL-2.1, and yt-dlp is Unlicense.

Does Garia collect any data?

No. There is no account, no analytics and no crash reporting. Apart from the downloads you ask for, the only thing Garia fetches is an update manifest from GitHub Releases. The browser extension only hands links to the app on your own Mac — see the extension privacy policy.

Why do downloads keep going after I close the window?

That's on purpose. The red button and ⌘W hide the window; the engine keeps running and the menu bar shows what's in flight. Click the Dock icon to bring the window back. ⌘Q is the only thing that stops downloads — and the queue picks up where it left off next time.

What makes it faster than my browser?

Garia asks the server for up to 16 pieces of a file at once and stitches them together, which often fills a connection a single stream can't. Downloads also resume after a network drop, sleep or restart instead of starting over.

Which sites can it download video from?

Anything yt-dlp supports, which is well over a thousand sites. If you already have a newer yt-dlp on your PATH, Garia prefers it. Please respect the terms of the sites you use and download only what you have the right to.

Is there a Windows or Linux version?

Not today. Garia is built for macOS 11 Big Sur and later, on Apple Silicon and Intel.

How do I report a bug or ask for a feature?

Check the issue tracker first, then open a new issue. Pull requests — including documentation fixes — are welcome.
