Outside the window downloads are paused, and anything queued is held rather than started. Only what Garia stopped is started again — a download you paused yourself stays paused. Garia has to be running for any of this. Closing the window is fine. Quit is what stops them. Nothing here wakes the Mac up.

Browser extension

Click a file in the browser and Garia takes it. Video pages are sent as pages, so yt-dlp can pick a quality.

More

Safari cannot cancel its own downloads, so the same package captures file-link clicks and the context menu; run scripts/make-safari-extension.sh once, then enable it under Safari → Settings → Extensions.
