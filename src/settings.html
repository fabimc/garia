    Browser

    When you copy a file link, Garia offers to download it. Web pages are ignored.

    Browser extension

    Click a file in your browser and Garia downloads it. On a video page, a Download button appears on the player.

    More

    Chrome, Edge, Brave, or Arc — open chrome://extensions, turn on Developer mode, Load unpacked, and choose the folder that opens. Firefox — open about:debugging#/runtime/this-firefox, Load Temporary Add-on, and pick manifest.json (it lasts until Firefox quits). Safari cannot stop its own downloads, so the same package catches file clicks, the context menu, and the on-page Download button; run scripts/make-safari-extension.sh once, then enable it under Safari → Settings → Extensions. Right-click a page to send every link, then uncheck the ones you don’t want. Hold Option while clicking a file to leave it with the browser. The player button sends the page, not the stream — × hides it until the next video.

    You can rename, pick a folder, or add to the queue. The bookmarklet and Services still start right away.

    Network

    Changing a login, cookie file, proxy, or remote control restarts the downloader. Unfinished files resume where they left off.

    Site logins

    For sites that need a username and password, including FTP.

    More

    Passwords stay on this Mac and are never attached to the download. Extra headers are sent with the request, so they are saved with it.
