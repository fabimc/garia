    Garia Help

    Add a download
    File → New Download (⌘N), or drop a torrent on the window. A magnet or .torrent the system opens is queued, not offered. In another app, select a URL and choose Services → Download with Garia. The bookmarklet in Settings → Capture sends the page you are on.
    The window is not the app
    The red button and ⌘W hide the list. Downloads keep going. ⌘Q is the only quit.
    The list
    Click selects. Double-click or Enter opens detail. Space pauses. ⌘C copies the URL. ⌘⌫ removes. Right-click for the rest.

    Licenses for the bundled tools are under Help → Licenses.
