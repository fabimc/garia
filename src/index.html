    Garia Help

    Add a download
    File → New Download (⌘N), Open Torrent (⌘O), or drop a torrent on the window. A magnet or .torrent the system opens is queued, not offered. In another app, select a URL and choose Services → Download with Garia. The browser extension in Settings (⌘,) → Browser takes a clicked file, and the bookmarklet sends the page you are on.
    The window is not the app
    The red button and ⌘W hide the list. Downloads keep going. ⌘Q is the only quit.
    The list
    Click selects. Arrows move the selection; ⌘A selects all. Double-click or Enter opens detail. Space pauses. ⌘C copies the URL. ⌘⌫ removes. ⌥↑ / ⌥↓ reorder a queued row — hold Shift for either end. Right-click also moves a selection to the top or the end, copies the file path, or removes the row and keeps the file. Download → Retry Failed and Clear Completed cover the whole list. ⌘F finds. ⌘? opens this sheet. Esc closes menus.
    Video downloads
    Paste a video page and pick a quality. Docs
    FTP
    Paste an ftp:// folder and tick what to queue. Docs
    Checksums
    Paste a hash beside the URL; aria2 checks as bytes arrive. Docs
    Torrents
    The Torrents filter is every magnet and .torrent. Open a row for tracker status, peer health, per-file priority, and Seed until. A row that says Stalled has the metadata and no peers.
    Schedule
    A daily window in Settings, or a start time on one row. Stop Queue / Start Queue are in the menu and the header. Docs
    Video button
    On a watch page the extension draws Download on the player; it sends the page, not the stream. Docs
    Leave with the browser
    Hold ⌥ while clicking a file link to leave that download with the browser. Docs

    Licenses for the bundled tools are under Help → Licenses.
