    Schedule

    Outside the window downloads are paused, and anything queued is held rather than started. Only what garia stopped is started again — a download you paused yourself stays paused, and one you resume during quiet hours is left running. Garia has to be running for any of this. Closing the window is fine — downloads keep going. Quit is what stops them. A window that starts at 2am starts at 2am if Garia is still running, or the next time you open it. Nothing here wakes the Mac up.

    A banner as each one lands, and a count on the dock icon for the ones that landed while you were somewhere else. Clicking the banner brings Garia back, and shows the file in Finder when it can.

    So overnight schedules and unfinished downloads do not wait for you to launch the app. Closing the window is still fine; this is about the Mac starting, not about leaving a window open.

    Video, Music, Documents, and Archives, inside the folder above. Anything else — and every torrent, which doesn't name its files until it starts — lands in the folder itself. Nothing already downloaded moves.

    aria2 normally takes whichever piece keeps a connection busiest, which finishes soonest but leaves holes near the front. In order, the file fills from the beginning and a row can be opened in a player while it downloads — at some cost to the speed. Applies to downloads added from now on.

    When you copy a download link, garia offers to take it. Pages and ordinary website URLs are left alone.

    Logins

    For files that are behind a sign-in. A password goes into a netrc file only aria2 reads, so it is never attached to a download and never reaches aria2's session file; a header is carried on the request, which means it is written down with it.

      A cookies.txt exported from the browser. aria2 matches it to hosts itself and reads it once, when it starts — so changing this restarts the download engine, and unfinished downloads resume where they were. Nothing is copied: the file stays where it is. Empty the box to stop using one.

      Remote control

      Opens the aria2 port to the whole network — there is no narrower setting than that — so any aria2 client on your phone can queue, pause and watch downloads. The secret below is the only thing standing in front of it, and it travels in the clear over plain HTTP: worth having at home, worth leaving off on a network you don't know. Turning it off deletes the secret, so every device paired against it is un-paired rather than merely shut out. Changing this restarts the download engine, and unfinished downloads resume where they were.
