    Garia Help

    Add a download
    File → New Download (Ctrl+N), Open Torrent (Ctrl+O), or drop a torrent on the window. A magnet or .torrent the system opens is queued, not offered. The browser extension in Settings (Ctrl+,) → Browser takes a clicked file, and the bookmarklet sends the page you are on.
    The window is not the app
    The close button and Ctrl+W hide the list. Downloads keep going. Ctrl+Q quits, and Tray → Quit stops downloads.
    The list
    Click selects. Arrows move the selection; Ctrl+A selects all. Double-click or Enter opens detail. Space pauses or resumes while the list has focus. Ctrl+C copies the URL. Ctrl+Backspace removes. Alt+↑ / Alt+↓ reorder a queued row — hold Shift for either end. Right-click also moves a selection to the top or the end, copies the file path, or removes the row and keeps the file. Download → Retry Failed and Clear Completed cover the whole list. Ctrl+F finds. Ctrl+? opens this sheet. Escape closes the topmost dialog, then the inspector.
    Show in folder
    Show in folder opens the download's containing folder and selects the file.
    Keyboard-only path
    Ctrl+N opens New Download; paste a URL and press Enter (Ctrl+Enter submits several). Tab to the sidebar, use ↑ / ↓ to choose a filter, then Enter. Focus the list for Space / Enter / Ctrl+C / Ctrl+Backspace — those keys stay with the focused control when the list is not focused. In the list, ↑ / ↓ selects; Space pauses or resumes. Ctrl+I opens details; Tab to reveal the file. Ctrl+F finds. Close the window to hide downloads; reopen Garia from the tray or app launcher. Ctrl+Q quits.
    Video downloads
    Paste a video page and pick a quality. Docs
    FTP
    Paste an ftp:// folder and tick what to queue. Docs
    Checksums
    Paste a hash beside the URL; aria2 checks as bytes arrive. Docs
    Torrents
    The Torrents filter is every magnet and .torrent. Open a row for tracker status, peer health, per-file priority, and Seed until. A row that says Stalled has the metadata and no peers.
    Schedule
    A daily window in Settings, or a start time on one row. Stop Queue / Start Queue are in the menu and the header. Docs
    Video button
    On a watch page the extension draws Download on the player; it sends the page, not the stream. Docs
    Leave with the browser
    Hold Alt while clicking a file link to leave that download with the browser. Docs

    Licenses for the bundled tools are under Help → Licenses.

    Welcome to Garia

    Linux / Omarchy: four quick checks before your first download.

    Download folder

    —

    New downloads go here. Confirm this location or choose another before adding a link.

    Browser

    In Omarchy Chromium, open chrome://extensions, enable Developer mode, choose Load unpacked, then select the folder opened by this button. Extension steps · Omarchy install notes

    Tray and login

    Closing the window hides Garia and leaves downloads running. Restore it from the tray, or launch it again if the tray is unavailable. Quit stops downloads. Notifications and login autostart are optional in Settings.

    Keyboard shortcuts

    Help lists the Ctrl shortcuts and a keyboard-only path from adding a download to managing it.
